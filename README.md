# DAITRA — E-Commerce Web Application

Luxurious gold & dark-themed designer boutique e-commerce web application with Google Sign-In, Brevo transactional emails, secure UPI gateway, and dynamic catalog database dashboard.

## Quick Start Server
- **Double click / Run Batch Script (Windows CMD)**: `start.bat`
- **PowerShell (Windows)**: `.\start.ps1`
- **Linux / macOS**: `./start.sh`

## Local Development Commands
- Run development server: `npm run dev`
- Build production bundle: `npm run build`
- Start production Node/Express server: `npm start` or `node server.js`
